# Security / 安全

## Supported release

Security fixes target the latest stable firmware release. Use the console's firmware update page or the [installation guide](docs/install.md) to update.

## Report a vulnerability

Use GitHub's private [Report a vulnerability](https://github.com/llm-net/llm-gate/security/advisories/new) form. If that form is unavailable, contact the maintainer privately through the [website contact section](https://llm.net/#contact). Do not post unpatched vulnerability details in public issues or pull requests.

Include the affected version, platform, impact, and minimal reproduction steps using synthetic data. Never include real API keys, session cookies, passwords, private keys, subscription credentials, prompts, model responses, or customer data. Coordinate any disclosure with the maintainer.

## 安全更新

安全修复面向最新稳定固件，请通过管理台固件升级页或[安装指引](docs/install.zh-CN.md)更新。

## 报告漏洞

请使用 GitHub 私密的 [Report a vulnerability](https://github.com/llm-net/llm-gate/security/advisories/new) 表单。表单不可用时，通过[官网联系入口](https://llm.net/#contact)私下联系维护者。未修复漏洞的细节不要发布到公开 Issue 或 PR。

请提供受影响版本、平台、影响范围与使用虚构数据的最小复现步骤。不要附带真实 API Key、会话 Cookie、口令、私钥、订阅凭据、提示词、模型响应或客户数据；披露安排请与维护者沟通。
