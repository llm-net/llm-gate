# Feedback and contribution policy / 反馈与贡献政策

LLM Gate firmware is free to download and use, with source available under the [MIT license](LICENSE). You may use, modify, and redistribute the firmware under that license.

This repository does **not accept external contributions or pull requests**. Pull requests are automatically closed with an explanation. The public repository contains firmware source snapshots and release downloads; the website and `gate` launcher source are not included.

For bug reports and feature feedback, use [GitHub Issues](https://github.com/llm-net/llm-gate/issues) or the [website contact section](https://llm.net/#contact). Include the firmware version, OS/architecture, reproduction steps, and expected versus actual behavior. Use synthetic examples and remove credentials, prompts, model responses, uploaded media, and personal data from diagnostics. Report security vulnerabilities privately using [SECURITY.md](SECURITY.md).

---
